# Проверка MVP «ЖКХ Контроль»

Документ описывает сценарий проверки этапов 1–4 после деплоя. Все команды
отправляются боту в MAX, а фотографии прикладываются к сообщению с командой.

## 1. Переменные на VPS

В `.env` должны быть заполнены:

```dotenv
APP_NAME=ЖКХ Контроль
MAX_BOT_TOKEN=...
INITIAL_ADMIN_MAX_USER_ID=<MAX ID администратора>
PUBLIC_BASE_URL=https://max.conspiracy-team.ru
MAX_WEBHOOK_SECRET=<не короче 5 символов>
TARANTOOL_PASSWORD=<пароль>
MINIO_ROOT_USER=minioadmin
MINIO_ROOT_PASSWORD=<длинный пароль>
```

Запуск выполняется обычным production-профилем:

```bash
docker compose --profile https up -d --build
docker compose logs -f bot
```

В логе должны появиться `MAX bot connected`, `Tarantool connected`,
`MinIO connected` и `control bot started`. Если MinIO или Tarantool ещё не
успели запуститься, приложение продолжит работу с предупреждением и повторит
подключение при следующем запуске.

## 2. Быстрый сценарий ролей

1. Администратор отправляет `/start`, затем `/admin`.
2. Администратор отправляет `/invite manager`. Бот выдаёт одноразовый код.
3. Руководитель отправляет `/join КОД`.
4. Администратор создаёт код исполнителя через `/invite employee`, после чего
   исполнитель отправляет `/join КОД`.
5. Администратор связывает пользователей командой:
   `/assign MAX_ID_исполнителя MAX_ID_руководителя`.
6. Руководитель создаёт задание:
   `/task Уборка лифта | Помыть кабину | MAX_ID_исполнителя | 2030-01-02`.
7. Исполнитель открывает `/tasks`, отправляет `/take ID`, прикладывает фото с
   `/before ID`, выполняет работу и отправляет фото с командой
   `/submit ID | Лифт убран, проверил поручни`.
8. Руководитель получает сообщение с кнопками «Принять» и «На переделку».
   Для переделки комментарий обязателен: `/rework ID | Нужно повторно протереть стены`.
9. После принятия исполнитель получает уведомление. При переделке он может
   повторить `/take ID`, `/before ID` и `/submit ID | ...` без ограничения числа
   попыток.

После `/start` или нажатия «Главное меню» навигация выполняется кнопками:
«Мои задания», «Создать задание», «Исполнители» и административные разделы.
В списке заданий можно открыть карточку задания и выполнить доступное действие
кнопкой; команды остаются доступны для случаев, когда MAX-клиент не показывает
inline-клавиатуру.

Дополнительные команды: `/help`, `/users`, `/block MAX_ID`,
`/unblock MAX_ID`, `/role MAX_ID manager`, `/object название | адрес`,
`/worktype название`, `/unable ID | причина`.

## 3. Что проверить технически

```bash
curl -fsS https://max.conspiracy-team.ru/healthz
curl -fsS https://max.conspiracy-team.ru/api/version
docker compose ps
docker compose logs --tail=100 bot tarantool minio caddy
```

Вебхук регистрируется автоматически при старте приложения как
`https://max.conspiracy-team.ru/webhook`; вручную заходить на VPS для каждой
пересборки не требуется, если деплой выполняет GitHub Actions. На главной
странице status page версия отображается в блоке `DEPLOYED VERSION`; при
деплое через workflow это SHA опубликованного коммита.
